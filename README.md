# 🚀 VigCraft Testing Hub

A modern Test Management and Automation Platform built to manage Manual Testing, API Testing, Playwright Automation, Test Execution, Defect Tracking, and Reporting from a single dashboard.

---

# 📌 Project Vision

VigCraft Testing Hub helps QA Engineers, Automation Testers, Developers, and Test Managers collaborate efficiently throughout the software testing lifecycle.

---

## Frontend
- HTML5
- CSS3
- JavaScript

## Backend
- Node.js
- Express.js

## Database
- MySQL

## Automation
- Playwright

## API Testing
- Postman
